PHOTO LIBRARY
=============
Put plant pictures in this folder (sub-folders are fine).

In the workbook, the IMAGE column holds the path *inside this folder*, for example:

    knockout-red.jpg
    roses/knockout-red.jpg

Tips
- Use .jpg, .jpeg, .png, .webp or .gif.
- Lowercase names with dashes (no spaces) avoid broken links.
- Aim for about 1200 pixels on the long side so pages load quickly.
